# Tushar Tyagi - 3D Portfolio

Welcome to the source code of my personal 3D Portfolio! This project showcases my skills, experience, and projects through an interactive, premium web experience.

## 🚀 Features

- **Interactive 3D Tech Stack**: A physics-based 3D environment built with React Three Fiber and Rapier physics to showcase the tools I use.
- **Smooth Animations**: High-performance scroll animations and transitions powered by GSAP.
- **Modern UI/UX**: Clean, glassmorphism-inspired design with a focus on dark mode aesthetics.
- **Fully Responsive**: Optimized for both desktop and mobile devices.

## 🛠️ Built With

- [React.js](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/)
- [GSAP (GreenSock)](https://greensock.com/gsap/)
- [TypeScript](https://www.typescriptlang.org/)

## 💻 Getting Started

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TusharTyagi2305/Tushar-Portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Tushar-Portfolio
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
